# Ferramenta de Controle de Investimentos com Excel

## Oobjetivo deste repositório é trazer alguns detalhes sobre como montar uma Ferramenta de Controle de Investimentos em Fundos Imobiliários utilizando o Excel para atender ao desafio de projeto "Criando uma Ferramenta de Controle de Investimentos com Excel" do Boorcamp "Santander - Excel com Inteligência Artificial - 2º Semestre" da DIO.

Para montarmos a ferramenta de forma eficiente devemos levar em conta algumas perguntas de negócio como:

Quanto investir por mês?

Por quantos anos?

Taxa de rendimento mensal?

Quanto de patrimônio acumulado terei?

Quanto são os dividendos mensais?
